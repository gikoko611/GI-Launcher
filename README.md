# G.I KO KO LAUNCHER

Gold / Myanmar Kanot themed Android launcher with a Cyber 3D animated theme. POWERED BY I KO KO.

- **dev branch** -> CI "Dev Build Check" (assembleRelease)
- **main branch** -> release CI: signed APK + GitHub Release

## Features (v0.0.1)
- Home screen with Cyber 3D animated background (perspective gold grid, glowing horizon, particles)
- Gold Myanmar Kanot vine border on all edges + kanot medallions on corners
- 3D gold "G.I" logo (Roman serif, shine + float animation) + POWERED BY I KO KO
- All installed app icons framed in gold kanot medallions
- Gold clock + date on home screen
- Dock (Phone / Message / Camera / Browser) + gold SETTINGS button
- Launcher Settings (gold themed): set as default launcher, generate gold cyber wallpaper for HOME + LOCK screen, cyber animation toggle
- Light for low-end devices
